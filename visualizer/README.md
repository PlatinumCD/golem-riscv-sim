# Mittens Flow Scope

Flow Scope is an opt-in, offline visualization subproject for Mittens/SST
activity. It shows an animated tile mesh and synchronized per-tile timeline
without exporting individual 32-bit beats or per-cycle router state.

The compact trace contains:

- task execution intervals;
- one movement event per logical tensor route;
- deterministic XY paths between source and destination tiles;
- receive-DMA intervals;
- analog set/load/compute/store/move intervals;
- nonzero tile waits; and
- aggregate link load and route-queue indicators.

Exact injection, arrival, DMA, task, analog, and wait timestamps come from
SST. Intermediate packet positions are a visual reconstruction along the
declared XY path; they are not a per-router trace.

## Opt-in export

Set `MITTENS_VISUALIZATION_EXPORT=1` when running a deployment test that
supports trace export.

The flag enables the detailed profile and task markers required to construct
the flow view, then writes:

```text
<deployment>/visualization/trace.json
```

No visualization trace or activity-export overhead exists when the flag is
unset. Since task markers are guest-visible MMIO, visualization runs are
diagnostic and should not supply official performance numbers.

Override the output directory with:

```bash
MITTENS_VISUALIZATION_DIRECTORY=/absolute/output/path
```

## View a trace

```bash
./visualizer/serve.sh 8000 \
  /absolute/path/to/trace.json
```

Open the printed URL. The server binds to `0.0.0.0`, so another device on the
same network can use the host machine's address.

The page also accepts a trace through the **Open trace** button. The default
sample is generated by:

```bash
./visualizer/tests/run-test.sh
```

## Controls

- Play, pause, step, seek, and change playback rate.
- Click a tile to inspect its current and aggregate activity.
- Click the timeline to seek; zoom from the complete run to a local window.
- Toggle task, route, analog, DMA, and wait layers independently.
- Active links turn gold; overlapping or queued traffic turns red.

## Deterministic movie

The `movie/` subproject converts a measured trace into one continuous,
linearly time-scaled H.264 movie. It adds packet header/payload intervals,
transmit-backpressure activity, critical-chain markers, and compiler task
metadata to the event presentation.

Use `render-movie.py` with an exported trace. See
[movie/README.md](movie/README.md) for the fidelity contract, frame mapping,
output files, and configurable resolution, duration, and frame rate.
